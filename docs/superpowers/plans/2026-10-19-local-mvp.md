# Notto Local MVP Implementation Plan

**Goal:** працездатний local-first MVP за наданим ТЗ.
**Architecture:** Router → services (ін'єкція repository contracts) → async SQLite. Zustand — лише UI.
**Tech Stack:** Expo 54, RN 0.81.5, TypeScript strict, RHF 7, Zustand 5, Jest.
**Spec:** docs/superpowers/specs/2026-10-19-local-mvp-design.md
**Execution:** самостійно в поточній сесії, як доручив користувач.

## Global Constraints

Український UI; жодних секретів Home Cellar; без backend; event_date YYYY-MM-DD, timestamps UTC; колір від типу; збереження даних при міграції.

## Review Focus

- Пробіли/Unicode/регістр у тегах — одна нормалізована назва.
- Високосні роки й часові пояси — стабільні календарні дати.
- Недійсний тип/тег — rollback нотатки та зв'язків.
- Видалення останнього типу — відмова без втрати нотаток.
- Пошук із %, _, лапками — без SQL/FTS помилок.
