# Notto — Ваші думки, впорядковані в часі

**Notto** — це мінімалістичний мобільний додаток, що є гібридом класичного записника та особистого щоденника. Він розроблений для тих, хто хоче не просто фіксувати корисну інформацію, ідеї, події чи важливі цитати, а й мати можливість миттєво відшукати їх у хронологічному порядку.

Головна філософія проекту — повна приватність, лаконічний інтерфейс та фокус на контенті без зайвого візуального шуму.

---

## 🚀 Основні можливості

* **Хронологічна стрічка (Timeline):** Усі нотатки автоматично прив'язуються до дати створення, формуючи красиву та зручну історію ваших думок і подій.
* **Інтуїтивний пошук за датами:** Швидка навігація через вбудований календар для пошуку записів за конкретний день чи період.
* **Локальне та надійне сховище:** Усі ваші дані зберігаються виключно на вашому пристрої. Жодних сторонніх серверів чи ризиків витоку інформації.
* **Легкість та швидкість:** Миттєвий запуск та плавна робота інтерфейсу завдяки оптимізації під мобільні платформи.

---

## 🛠 Технологічний стек

Проект побудований на сучасних та перевірених інструментах мобільної розробки:

* **Фреймворк:** [React Native](https://reactnative.dev/) (для створення кросплатформеного додатка під iOS та Android з єдиною кодовою базою).
* **Платформа розробки:** [Expo](https://expo.dev/) (Expo SDK для швидкого прототипування, легкого тестування та налаштування середовища).
* **База даних:** [SQLite](https://www.sqlite.org/) (за допомогою `expo-sqlite` для високопродуктивного локального збереження структурованих даних).
* **Керування станом & Навігація:** React Navigation / Expo Router.

## 🗄 Схема бази даних (SQLite)

Локальна база даних містить таблицю `notes` із такою базовою структурою:

```sql
CREATE TABLE IF NOT EXISTS notes (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT,
    content TEXT NOT NULL,
    created_at TEXT NOT NULL, -- Зберігається у форматі ISO 8601 (YYYY-MM-DD)
    updated_at TEXT
);

```

## 💻 Налаштування та запуск

Щоб запустити проект локально, виконайте наступні кроки.

### Попередні вимоги

Переконайтеся, що на вашому комп'ютері встановлено:

* [Node.js](https://nodejs.org/) (рекомендовано версію LTS)
* Мобільний додаток **Expo Go** на вашому смартфоні (iOS/Android) для тестування.

### 1. Клонування репозиторію

```bash
git clone [https://github.com/your-username/notto.git](https://github.com/your-username/notto.git)
cd notto

```

### 2. Встановлення залежностей

```bash
npm install
# або, якщо ви використовуєте yarn:
yarn install

```

### 3. Запуск сервера розробки Expo

```bash
npx expo start

```

Після запуску ви побачите QR-код у терміналі. Відскануйте його за допомогою камери смартфона (для iOS) або додатка Expo Go (для Android), щоб запустити додаток на своєму пристрої.
